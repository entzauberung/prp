# 4. Non-goals

This protocol does not specify:

- Where execution lives (`CLOUD`, `BRIDGE`, `LOCAL`)
- How a model provider is called
- Which tools exist on a machine
- HTTP, SSE, SQLite, or any other transport
- Operating-system isolation
- Billing, multi-tenancy, or SLA
- Compatibility with Codex, Claude Code, MCP, or A2A
- Training, fine-tuning, or leaderboard claims

An agent product may need all of the above. PRP does not.

## Research non-claims

Related work listed in `paper/related-work.md` is context.
This repository does not claim to reproduce those papers, to beat their
benchmarks, or to have completed an evaluation.

# WO-002-ST-001 Settings 严格环境 JSON 行为测试

## 子任务目标

证明 `Settings.from_env` 通过实际配置入口拒绝 NaN、Infinity、-Infinity 和溢出为 infinity 的数字。

## 执行顺序

1. 阅读 `_profile_from_json`、`Settings.from_env` 和现有 settings 集成测试。
2. 在 `test_base.py` 增加参数化非标准数字环境 JSON 测试。
3. 断言配置构造被拒绝，不绑定完整 Pydantic 错误文本。
4. 运行当前测试文件和目标 ruff。
5. 仅在测试证明 strict helper 未实际生效时修复 `settings.py` 并重跑同一命令。

## 精确实施要求

- 参数至少覆盖 `NaN`、`Infinity`、`-Infinity`、`1e999`。
- 非标准值必须出现在合法 profile JSON 的数值字段中，避免测试只因缺字段失败。
- 使用 `Settings.from_env`，不得直接测试 helper 冒充边界测试。
- 现有实现通过时只改测试，不重写 settings。

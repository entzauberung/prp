# WO-002-ST-003 SQLite 事件非有限 payload 零落库测试

## 子任务目标

通过 `SqliteStore.append_event` 证明非有限 payload 在写入时被拒绝，事务后事件表保持不变。

## 执行顺序

1. 阅读 append/list event 实现和现有事件存储测试。
2. 使用临时 Store 和已持久 Run 构造事件写入场景。
3. 参数化 NaN、正负 Infinity；断言 append 抛 ValueError。
4. 每次拒绝后读取事件列表并断言没有新增行。
5. 保留有限 payload 正常往返断言，运行目标 pytest/ruff。
